# Loris Codex Pet v3 / 萝莉斯 Codex 桌宠 v3

Free, non-commercial distribution only. This is an unofficial adaptation of Loris from VPet Simulator. Read `NOTICE.md` before using or redistributing the animation-derived files.

仅限免费、非商业分发。本项目是《虚拟桌宠模拟器》萝莉斯的非官方适配。使用或再分发由动画衍生的文件前，请阅读 `NOTICE.md`。

## Install / 安装

1. Copy this entire `loris-vpet` folder to `%USERPROFILE%\.codex\pets\loris-vpet`.  
   将整个 `loris-vpet` 文件夹复制到 `%USERPROFILE%\.codex\pets\loris-vpet`。
2. Keep `pet.json` and `spritesheet.webp` together.  
   请始终让 `pet.json` 和 `spritesheet.webp` 保持在同一文件夹中。
3. Restart Codex, or refresh and select **Loris** in **Settings > Pets**.  
   重启 Codex，或者在**设置 > Pets**中刷新并选择 **Loris**。

To update, replace both core files together. To remove, close Codex and delete the installed `loris-vpet` folder.

更新时请同时替换两个核心文件；删除时请先关闭 Codex，再移除已安装的 `loris-vpet` 文件夹。
